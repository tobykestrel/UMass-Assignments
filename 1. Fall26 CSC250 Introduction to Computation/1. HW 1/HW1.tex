	\end{enumerate}

So, for example, the set $S = \{5,5,5, 1\}$ is actually the same as the set $S = \{5,1\}$ and has $sum(S) =6,$ and not $16.$ }

	\subsection*{\textbf{Solution:}}
	\begin{enumerate}[(a)]
		\item In addition to the empty set (0), there are other naturals n for which
			there is exactly one set S with sum(S)=n; there is n=1 which is just the
			set \{1\}, and n=2 which is just the set \{2\}. Those however, are all of them;
			For any value of n greater than 2, there are at least the sets of the number
			itself \{n\}, and the number itself minus 1 and 1 itself \{1,n-1\}.

		\item
			\[
				\{10\},\quad \{1,9\},\quad \{2,8\},\quad \{3,7\},\quad \{4,6\},\quad
			\]
			\[
				\{1,2,7\},\quad \{1,3,6\},\quad \{1,4,5\},\quad \{2,3,5\},\quad \{1,2,3,4
				\}
			\]

		\item It is NOT possible for $S \subseteq T$ or for $T \subseteq S$ if S and
			T are unique sets that have the same sum. This is because subsets require
			possessing items ONLY from the superset, and since everything in the sets are
			positive, there's no way for the subset to reach the same sum without
			additional numbers or by being the entire original set (which is not the case
			since its outright stated that $S \not= T$).
	\end{enumerate}

	\section*{\textbf{Problem 4. Modification of Problem 1.1.10 in the book} [10
	pts]}

	Let $D$ be a set of dogs, $R$ a set of retrievers, and $G$ a set of golden retrievers.
	Assume that $G \subseteq R$ and $R \subseteq D.$ For each of parts (a)-(d)
	below first answer (i) and then, starting on a new line, for (ii), provide a complete
	logical justification as to why your answer is correct. Your justification
	must use full sentences.

	Proving that a number is the minimum number satisfying a property requires
	proving {\em both} that the number satisfies the property {\em and} that no
	smaller number satisfies that property.

	\begin{enumerate}[(a)]
		\item (i) With no other information, what is the minimum number of dogs that
			must exist? (ii) Justify your answer

		\item Suppose we know that all three sets are different from each other. (i)
			What is the minimum number of dogs that satisfy this constraint? (ii) Justify
			your answer.

		\item Suppose we know that no set is empty and that all sets are different from
			each other. (i) What is the minimum number of dogs that satisfy this
			constraint? (ii) Justify your answer.

		\item Suppose we know that $D \neq G$ but that the three sets are not all different.
			(i) What is the minimum number of dogs that satisfy this constraint? (ii) Justify
			your answer.
	\end{enumerate}

	\subsection*{\textbf{Solution:}}

	\begin{enumerate}[(a)]
		\item (i) Zero (0) \\
			(ii) The minimum amount of dogs that must exist is zero (0), because the
			only information that we are given is the subset order ($G \subseteq R$ and
			$R \subseteq D.$). With no note of how many dogs are in any given set, we
			can assume that theoretically, D is just an empty set, R is just the empty
			subset of that empty set, and G is just the empty subset of that empty subset
			of that empty set. Since there is no amount of items a set can have that
			is less than zero, zero MUST be the minimum amount of dogs.

		\item (i) Two (2) \\
			(ii) Given that three sets of dogs are subsets of each other ($G \subseteq
			R$
			and $R \subseteq D.$), and that each set has a different amount of dogs in
			it, we can safely assume that there are two dogs at the very minimum. This
			is because the three lowest amount of items a set can have is zero, one,
			and two; and since the subsets contain only dogs from their supersets, we
			only need to look at the lowest value the SUPERSET can be, which must be the
			highest of the three lowest amount of items a set can have (2), since the
			subsets can't contain items outside of the superset, but the superset CAN contain
			items outside of the subset.

		\item (i) Three (3) \\
			(ii) Given that three sets of dogs are subsets of each other ($G \subseteq
			R$
			and $R \subseteq D.$), and that each set has a different amount of dogs in
			it thats more than zero, we can safely assume that there are three dogs at
			the very minimum. This is because the three lowest amount of items a set
			can have other than zero is one, two, and three; and since the subsets contain
			only dogs from their supersets, we only need to look at the lowest value
			the SUPERSET can be, which must be the highest of the three lowest amount of
			items a set can have other than zero (3), since the subsets can't contain
			items outside of the superset, but the superset CAN contain items outside of
			the subset.

		\item (i) One (1) \\
			(ii) Given that D is not the same set as G, we can safely assume that
			there is at least 1 dog at the very minimum. This is because assuming the subset
			is the empty set (the lowest amount of items a set can have), the next
			lowest amount of items a set can have is 1, and since D is NOT G, it must
			at LEAST have a count of 1.
	\end{enumerate}

	\section*{\textbf{Problem 5. P1.4.3 in the book} [10 pts]}
	Another boolean operation is the ``NAND'' operation. where ``$x \ \mbox{\bf
	nand}\  y$'' is defined to be $\neg(x \wedge y).$
	\begin{enumerate}[(a)]
		\item Explain why $x \ \mbox{\bf nand}\  x$ is equivalent to $\neg x.$

		\item Can you find a compound proposition using only the NAND operator that is
			equivalent to $x \wedge y$? If yes, write it down.

		\item Can you find a compound proposition using only the NAND operator that is
			equivalent to $x \vee y$? If yes, write it down.
	\end{enumerate}
	{\em Hint: In parts (b) and (c) you are permitted to use the NAND operator multiple times. \par\noindent Historical Note: Historically, this had implications in hardware design, since {\bf nand} gates were easier to physically build than {\bf and} or {\bf or} gates.}

	\subsection*{\textbf{Solution:}}
	\begin{enumerate}[(a)]
		\item $x \ \mbox{\bf nand}\ x$ is equivalent to $\neg x$ because the output of
			both expressions will always be the opposite of $x$'s value (if $x$ is
			true, the expression is false; if $x$ is false, the expression is true). As
			a proof it would look like this:
			\[
				\begin{array}{rcll}
					x \ \mbox{\bf nand}\ x & = & \neg(x \wedge x) & \mbox{Definition of {\bf nand}} \\
					                       & = & \neg x           & \mbox{E6(a). Equal Operands}
				\end{array}
			\]

		\item The compound proposition $(x \ \mbox{\bf nand}\ y) \ \mbox{\bf nand}\ (
			x \ \mbox{\bf nand}\ y)$ is equivalent to $x \wedge y$.
			\[
				\begin{array}{rcll}
					(x \ \mbox{\bf nand}\ y) \ \mbox{\bf nand}\ (x \ \mbox{\bf nand}\ y) & = & \neg\bigl(\neg(x \wedge y) \wedge \neg(x \wedge y)\bigr) & \mbox{Definition of {\bf nand}} \\
					                                                                     & = & \neg\neg(x \wedge y)                                     & \mbox{E6(a). Equal Operands}    \\
					                                                                     & = & x \wedge y                                               & \mbox{E9. Double Negative}
				\end{array}
			\]

		\item The compound proposition $(x \ \mbox{\bf nand}\ x) \ \mbox{\bf nand}\ (
			y \ \mbox{\bf nand}\ y)$ is equivalent to $x \vee y$.
			\[
				\begin{array}{rcll}
					(x \ \mbox{\bf nand}\ x) \ \mbox{\bf nand}\ (y \ \mbox{\bf nand}\ y) & = & \neg(\neg(x \wedge x) \wedge \neg(y \wedge y)) & \mbox{Definition of {\bf nand}} \\
					                                                                     & = & \neg(\neg x \wedge \neg y)                     & \mbox{E6(a). Equal Operands}    \\
					                                                                     & = & x \vee y                                       & \mbox{E10(b). DeMorgan's Law}
				\end{array}
			\]
	\end{enumerate}

			(ii) Given the formula $\frac{n(n+1)}{2}$, which calculates the total
			number of nonempty intervals in a set of $n$ consecutive numbers; plugging
			in $n=10$ gives $\frac{10(10+1)}{2}=\frac{10(11)}{2}=\frac{110}{2}=55$. By
			convention the additional empty set interval brings the total to 56 ($55+1=
			56$).

		\item (i) Sixteen (16) \\
			(ii) Given the formula $\frac{n(n+1)}{2}$, which calculates the total
			number of nonempty intervals in a set of $n$ consecutive numbers; plugging
			in $n=5$ gives $\frac{5(5+1)}{2}=\frac{5(6)}{2}=\frac{30}{2}=15$. By
			convention the additional empty set interval brings the total to 16 ($15+1=
			16$). Since all intervals are subsets, and every interval within
			{2,3,4,5,6} is also an interval within X, the total amount of intervals within
			X that are subsets of {2,3,4,5,6} is just the amount of intervals that {2,3,4,5,6}
			has (16).

		\item (i) Forty (40) \\
			(ii) The amount of intervals that are disjoint from {2,3,4,5,6} is equal to
			the total amount of the interval in X MINUS the amount that are subsets of
			{2,3,4,5,6}; in other words, it is $56-16=40$.
	\end{enumerate}

	\section*{\textbf{Problem 7. P1.7.6 in the book} [10 pts]}
	Suppose we substituted $a \oplus b$ for $p$ and $a \land b$ for $q$ in the contrapositive
	rule $(p \rightarrow q) \leftrightarrow (\neg q \rightarrow \neg p)$ to get
	\[
		\Bigl((a \oplus b) \rightarrow (a \land b)\Bigr) \leftrightarrow \Bigl((\neg
		a \land b) \rightarrow (\neg a \oplus b)\Bigr).
	\]

	\begin{enumerate}[(a)]
		\item Verify that this result is \textit{not} a tautology.\\
			{\em \small Note: Your verification should be in the same format as those in Section 7 of the Equational and Deductive Sequence Proofs Study Guide.}

		\item Why didn’t our substitution lead to a valid tautology? Explain.
	\end{enumerate}

	\subsection*{\textbf{Solution:}}
	\begin{enumerate}[(a)]
		\item
			\noindent
			Set $a=1$ and $b=0$. Then
			$\Bigl((a \oplus b) \rightarrow (a \land b)\Bigr) \leftrightarrow \Bigl((\neg
			a \land b) \rightarrow (\neg a \oplus b)\Bigr)$
			evaluates to

			\[
				\scriptsize
				\begin{array}{rcll}
					\Bigl((1 \oplus 0) \rightarrow (1 \land 0)\Bigr) \leftrightarrow \Bigl((\neg 1 \land 0) \rightarrow (\neg 1 \oplus 0)\Bigr) & = & \Bigl((1 \oplus 0) \rightarrow (1 \land 0)\Bigr) \leftrightarrow \Bigl((0 \land 0) \rightarrow (0 \oplus 0)\Bigr) & \mbox{Definition of $\neg$, applied twice}        \\
					                                                                                                                            & = & \Bigl(1 \rightarrow (1 \land 0)\Bigr) \leftrightarrow \Bigl((0 \land 0) \rightarrow 0\Bigr)                       & \mbox{Definition of $\oplus$, applied twice}      \\
					                                                                                                                            & = & (1 \rightarrow 0) \leftrightarrow (0 \rightarrow 0)                                                               & \mbox{Definition of $\land$, applied twice}       \\
					                                                                                                                            & = & 0 \leftrightarrow 1                                                                                               & \mbox{Definition of $\rightarrow$, applied twice} \\
					                                                                                                                            & = & 0                                                                                                                 & \mbox{Definition of $\leftrightarrow$}
				\end{array}
			\]

			\noindent
			Since the proposition evaluates to $0$ for the truth setting $a=1$ and
			$b=0$, it is NOT a tautology.

		\item The reason our substitution didn't lead to a valid tautology is that we
			didn't substitute correctly. The negation operator was supposed to be on
			the outside of either expression on the right side of the comparison
			operator, not inside the expression attached to only the variable $a$. The
			proper substitution would look like this:
			\[
				\Bigl((a \oplus b) \rightarrow (a \land b)\Bigr) \leftrightarrow \Bigl(\neg
				(a \land b) \rightarrow \neg( a \oplus b)\Bigr).
			\]
			\\
			To prove it, here is the evaluation of the correct substitution:
			\[
				\scriptsize
				\begin{array}{rcll}
					\Bigl((1 \oplus 0) \rightarrow (1 \land 0)\Bigr) \leftrightarrow \Bigl(\neg(1 \land 0) \rightarrow \neg(1 \oplus 0)\Bigr) & = & \Bigl(1 \rightarrow (1 \land 0)\Bigr) \leftrightarrow \Bigl(\neg(1 \land 0) \rightarrow \neg 1\Bigr) & \mbox{Definition of $\oplus$, applied twice}      \\
					                                                                                                                          & = & (1 \rightarrow 0) \leftrightarrow (\neg 0 \rightarrow \neg 1)                                        & \mbox{Definition of $\land$, applied twice}       \\
					                                                                                                                          & = & (1 \rightarrow 0) \leftrightarrow (1 \rightarrow 0)                                                  & \mbox{Definition of $\neg$, applied twice}        \\
					                                                                                                                          & = & 0 \leftrightarrow 0                                                                                  & \mbox{Definition of $\rightarrow$, applied twice} \\
					                                                                                                                          & = & 1                                                                                                    & \mbox{Definition of $\leftrightarrow$}
				\end{array}
			\]
	\end{enumerate}

	Let $A$, $B$, and $C$ be sets defined in Exercise $2.1.1$ in the textbook\footnote{i.e.,

			$\times$ ($B \times C$). (Note that an element of $A$ $\times$ ($B \times C$)
			is a pair whose first element is in $A$ and whose second element is in $B \times
			C$.)

		\item If $X$, $Y$, and $Z$ are any sets, we generally do not distinguish
			among $X$ $\times$ ($Y \times Z$), ($X \times Y$) $\times$ $Z$, and the
			set of triples $X \times Y \times Z$. Explain how we may think of an element
			of each of these sets as an element of one of the others, by describing
			which elements of each set correspond to which elements of the others.
	\end{enumerate}

	\medskip

	\subsection*{\textbf{Solution:}}

	\begin{enumerate}[(a)]
		\item
			\[
				\begin{aligned}
					(A \times B) \times C = \{ & ((1,x),\text{cat}), ((1,x),\text{dog}),    \\
					                           & ((1,y),\text{cat}), ((1,y),\text{dog}),    \\
					                           & ((1,z),\text{cat}), ((1,z),\text{dog}),    \\
					                           & ((2,x),\text{cat}), ((2,x),\text{dog}),    \\
					                           & ((2,y),\text{cat}), ((2,y),\text{dog}),    \\
					                           & ((2,z),\text{cat}), ((2,z),\text{dog}) \}.
				\end{aligned}
			\]

			\[
				\begin{aligned}
					A \times (B \times C) = \{ & (1,(x,\text{cat})), (1,(x,\text{dog})),    \\
					                           & (1,(y,\text{cat})), (1,(y,\text{dog})),    \\
					                           & (1,(z,\text{cat})), (1,(z,\text{dog})),    \\
					                           & (2,(x,\text{cat})), (2,(x,\text{dog})),    \\
					                           & (2,(y,\text{cat})), (2,(y,\text{dog})),    \\
					                           & (2,(z,\text{cat})), (2,(z,\text{dog})) \}.

			different with the groupings since the parenthesis enclose around different
